# car-game-

A lightweight browser car dodging game.

## How to play

1. Open `index.html` in your browser.
2. Press `Space` (or click **Start**) to begin.
3. Move left/right with arrow keys or `A` / `D`.
4. Avoid enemy cars as long as possible.

## Features

- Increasing difficulty as score grows
- Persistent best score with `localStorage`
- Keyboard and click/tap controls
